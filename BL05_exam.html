大問 1 DNAとRNAの構造（穴埋め）
次の文章を読み、空欄 ア〜ウ に当てはまる語句を語群から選んでください。

DNAもRNAも多数の が鎖状につながってできている。この構成単位は糖・塩基・リン酸の3部品からなる。

RNAはDNAと共通するが、1本鎖であり、構成する糖と の種類が異なる。RNAの糖は である。

✅ 解説

ア＝ヌクレオチド：DNAもRNAも「ヌクレオチド」という単位が鎖状につながった高分子です。

イ（空欄2）＝塩基：DNAとRNAでは構成する糖と塩基の種類が異なります。DNAの塩基はA・T・G・Cの4種類で、RNAではTの代わりにU（ウラシル）が使われます。

ウ（空欄3）＝リボース：RNAの糖はリボースです。DNAの糖（デオキシリボース）とは酸素原子がひとつちがいます。「デオキシ（de-oxy）」は「酸素が足りない」という意味で、リボースからOHの一部がHになったものがデオキシリボースです。

大問 2 DNA二重らせん構造の図の読み取り
図はDNAの構造を示しています。次の各問いに答えてください。
図：(a) 二重らせん構造のDNA　(b) らせんを開いたDNA　(c) ヌクレオチド鎖の拡大
問1

図(a)のDNA二重らせん構造に関する説明として正しいものを選んでください。

  • ①らせん1回転の中に含まれる塩基対は約5個である。
  • ②2本のヌクレオチド鎖は同じ方向（平行）に走っている。
  • ③らせん1回転の中に含まれる塩基対は約10個である。
  • ④2本の鎖はタンパク質によって結びついている。
✅ 正解：③

DNA二重らせんは1回転あたり約10塩基対含まれます（図(a)の左側に「らせん1回転の間に10塩基対」と記されています）。

①は5個で誤り。②の2本の鎖は逆向き（逆平行）に走っています。④の2本の鎖は水素結合（タンパク質ではない）で結びついています。
問2

図(c)のヌクレオチドの構成部品として正しい組み合わせを選んでください。

  • ①リン酸・リボース・塩基
  • ②リン酸・デオキシリボース・塩基
  • ③リン酸・グルコース・塩基
  • ④アミノ酸・デオキシリボース・塩基
✅ 正解：②

DNAのヌクレオチドはリン酸・デオキシリボース（糖）・塩基の3つからできています。図(c)でも「リン酸」「糖（デオキシリボース）」「塩基」と表示されています。

①のリボースはRNAの糖です。③のグルコースはエネルギー源の糖で、核酸の材料ではありません。④のアミノ酸はタンパク質の材料です。
問3

あるDNAを調べたところ、A（アデニン）が全塩基の25%を占めていました。G（グアニン）の割合は何%ですか。

  • ①25%
  • ②20%
  • ③30%
  • ④35%
✅ 正解：① 25%

相補性（シャルガフの法則）より A＝T、G＝C が成り立ちます。

A＝25% → T＝25%（A＝Tより）
A＋T＝50% → 残り50%がG＋C
G＝C なので G＝C＝50%÷2＝25%

Aが25%のときGも25%になります。A＝T＝G＝C＝25%というのは特殊なケースで、常にそうなるわけではありません（AとGが等しいのは偶然ではなく、この問題の数値設定によるものです）。
問4

あるDNAの一方の鎖の塩基配列が 5'—ATGCCA—3' のとき、もう一方の鎖（相補鎖）の塩基配列として正しいものを選んでください。

  • ①ATGCCA
  • ②TACGGT
  • ③UACGGU
  • ④GCATCC
✅ 正解：②

相補性の法則（A↔T、G↔C）を1塩基ずつ適用します。

元の鎖：A　T　G　C　C　A
相補鎖：T　A　C　G　G　T

①は同じ配列で誤り。③のUはウラシルでRNA専用の塩基です（DNAにはUは存在しない）。④はペアの対応がちがいます。
大問 3 DNA抽出実験（過去問類題）
過去問類題：ブロッコリーの花芽を使ったDNA抽出実験の会話文
問1

会話文の空欄ア（ブロッコリーの花芽を使う理由）として最も適切なものを選んでください。

  • ①他の植物より核が大きいため
  • ②細胞の中で核が占める割合が大きいため
  • ③細胞壁がないため
  • ④DNAが核の外に存在するため
✅ 正解：②

ブロッコリーの花芽を使う理由は、細胞の中で核が占める割合が大きいからです。核が多いということはDNA量も多く、取り出せるDNAの量が増えます。

①は「核が大きい」ではなく「核の割合が大きい」が正しい。③植物細胞には細胞壁があります。④DNAは通常、核の中に存在します。
問2

会話文の空欄イ（抽出液に台所用洗剤のほかに含まれているもの）として正しいものを選んでください。
ヒント：「DNAは食塩水に溶けやすく、冷たいエタノールには溶けにくい」

  • ①食塩水（塩化ナトリウム水溶液）
  • ②エタノール
  • ③酢酸カーミン液
  • ④塩酸
✅ 正解：①

DNAは食塩水（塩化ナトリウム水溶液）に溶けやすい性質があります。そのため抽出液には台所用洗剤（細胞膜・核膜のリン脂質を溶かす）と食塩水（DNAを溶け出させる）が含まれています。

②エタノールはこの段階ではなく、後でろ液に加えてDNAを析出させるために使います。③酢酸カーミン液はDNAの染色試薬です。④塩酸はBL06の細胞分裂実験で細胞を解離させるために使いますが、DNA抽出では使いません。
問3

ろ液に氷冷エタノールを加えると白い繊維状のものが現れました。この白い繊維状のものは何ですか。また、なぜエタノールを加えると析出するのか、その理由として正しいものを選んでください。

  • ①タンパク質が析出する。タンパク質はエタノールに溶けないため。
  • ②DNAが析出する。DNAはエタノールによって分解されるため。
  • ③DNAが析出する。DNAは食塩水には溶けるがエタノールには溶けないため。
  • ④細胞壁の成分が析出する。エタノールが細胞壁を溶かすため。
✅ 正解：③

白い繊維状のものはDNAです。DNAは食塩水（イオン溶液）には溶けますが、エタノールには溶けません。そのため、ろ液（食塩水）にエタノールを加えると、DNAがエタノールに触れて溶けられなくなり、白い繊維状の固まりとして析出（沈殿）します。

①析出するのはタンパク質ではなくDNAです。②DNAはエタノールで分解されるわけではなく、単に溶けないために析出します。④細胞壁の成分はろ過の段階で取り除かれています。
大問 4 転写・翻訳とタンパク質合成（過去問類題）
図2：DNAの塩基配列 → 転写 → mRNAの塩基配列 → 翻訳 → タンパク質の流れ
問題文：DNAの遺伝情報をもとにしたタンパク質合成の説明
問1

問題文の空欄ク（酵素や筋肉の主成分）として正しいものを選んでください。

  • ①DNA
  • ②炭水化物
  • ③タンパク質
  • ④脂質
✅ 正解：③

酵素や筋肉の主成分はタンパク質です。DNAの遺伝情報をもとに合成されるのがタンパク質で、体の構造（筋肉・毛髪など）や機能（酵素・ホルモンなど）の中心となる物質です。

問2

問題文の空欄ケ（タンパク質が多数つながった単位）として正しいものを選んでください。

  • ①ヌクレオチド
  • ②グルコース
  • ③脂肪酸
  • ④アミノ酸
✅ 正解：④

タンパク質は多数のアミノ酸が鎖状につながった物質です。タンパク質の種類・数・配列によってタンパク質の性質が決まります。

①ヌクレオチドはDNA/RNAの構成単位。②グルコースは糖（炭水化物）の構成単位。③脂肪酸は脂質の構成単位です。
問3

図2で、DNAの3個の塩基TGAが転写されると、mRNAの塩基配列（コドン）はどうなりますか。正しいものを選んでください。
※RNAではTの代わりにU（ウラシル）が使われます。

  • ①ACU
  • ②TGA
  • ③ACT
  • ④UGA
✅ 正解：① ACU

転写では、DNAの塩基配列に相補的なmRNAが合成されます。RNAではDNAのTに対応してU（ウラシル）が使われます。

DNAの鋳型鎖：T → mRNA：A
DNAの鋳型鎖：G → mRNA：C
DNAの鋳型鎖：A → mRNA：U
よって TGA → ACU

②TGAはDNAの配列そのままで誤り。③ACTのTはDNAの塩基でRNAには使われません（RNAではUを使う）。④UGAはDNAのTCAに対応するmRNAの配列です。
大問 5 転写の模式図の読み取り（過去問類題）
DNAからRNAが転写されるようすを示した模式図①〜④のうち、正しいものを選んでください。
A＝アデニン、G＝グアニン、C＝シトシン、T＝チミン、U＝ウラシルを示しています。
転写の模式図 ①②（DNAからmRNAが合成される方向と塩基対）
転写の模式図 ③④
問1

転写の模式図として正しいものを①〜④から選んでください。
ポイント：① RNAにはTではなくUが使われる　② RNA塩基はDNAの相補性（A-U、T-A、G-C、C-G）で決まる

  • ①図①（RNAにTが含まれている）
  • ②図②（RNAにUが含まれている・DNAのTに対してAが対応）
  • ③図④（RNAにUが含まれているが、配列が合っていない）
  • ④図③（RNAにUが含まれている・DNAのAに対してUが対応）
✅ 正解：④

転写の規則は次の通りです。

DNAの鋳型鎖 A → mRNA U
DNAの鋳型鎖 T → mRNA A
DNAの鋳型鎖 G → mRNA C
DNAの鋳型鎖 C → mRNA G

①はRNAにTが含まれている時点で誤りです（RNAにTはない）。②はDNAのTに対してAではなくUになるはずなので誤りです。④はDNAのAに対してU（ウラシル）が対応しており正しい組み合わせです。③は配列に誤りがあります。

大問 6 だ腺染色体実験（過去問類題）
だ腺染色体のDNAとRNAの分布を観察する実験（ユスリカの幼虫）
問1

問題文の空欄サ（しま模様に含まれるもの）として正しいものを選んでください。
メチルグリーンはDNAを青〜青緑色に、ピロニンはRNAを赤桃色に染色します。しま模様は青緑色に染まっています。

  • ①RNA
  • ②DNA
  • ③タンパク質
  • ④脂質
✅ 正解：②

しま模様が青緑色に染まったということは、メチルグリーンで染まったということです。メチルグリーンはDNAを染める試薬なので、しま模様にはDNAが含まれます。

問2

問題文の空欄シ（矢印のふくらんでいる部分に含まれるもの）として正しいものを選んでください。
ふくらんでいる部分（パフ）は赤桃色に染まっています。

  • ①RNA
  • ②DNA
  • ③タンパク質
  • ④脂質
✅ 正解：①

ふくらんでいる部分（パフ）が赤桃色に染まったということは、ピロニンで染まったということです。ピロニンはRNAを染める試薬なので、パフにはRNAが含まれます。

パフはDNAが部分的にほどけてRNA合成（転写）が盛んに行われている場所です。

問3

問題文の空欄ス（パフでは何が行われているか）として正しいものを選んでください。

  • ①DNAの複製
  • ②翻訳
  • ③細胞分裂
  • ④転写
✅ 正解：④

パフにRNAが多く存在するということは、その部分でDNAからRNAが盛んに合成されていることを意味します。DNAの情報をRNAに写し取る過程を転写といいます。

①DNAの複製はS期に行われ、パフとは別の現象です。②翻訳はリボソームでRNAの情報をもとにタンパク質を合成する過程で、核の外で行われます。③細胞分裂はパフと直接関係しません。
